MAGIC SQUARES
A fun and educational application that generates and validates 
Magic Squares—where the sums of numbers in rows, columns, and 
diagonals are all equal. This project blends logic, math, and 
interactive design to help users explore mathematical patterns 
and puzzle-solving.

How-To-Play: Rules
For the 3x3 - magic square
- A number is given at the center. 5
- You are suppose to place numbers.
- Each row, column and diagonal should sum up to 15.
